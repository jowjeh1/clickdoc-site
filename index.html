How it works

1. Record

Give the guide a title and press start. Do the task in any tab, on any site.

2. Every click becomes a step

Links, buttons, tabs, typed fields, dropdowns. Each with a screenshot and a highlight. Passwords are masked.

3. Hand it over

Edit the text, reorder, then download one HTML file with the pictures inside, copy Markdown, or print to PDF.
